Install guide

The one-line install and the downloads are on the home page. This page has the details: what each installer does, the first run on every system, and what you need.

One-line installClient downloads

Checksums: SHA256SUMS. Version …. File sizes show on each download.

Server

One script checks Docker, downloads Cyber-Scout and the robot detector model, starts it and prints the address and a one-time setup code. Re-run it any time to update.

The one-line install does all of this for you: it downloads the installer, the code and the detector model from this site and checks their SHA-256. It works on computers that can reach this site (this address): the same network, or a VPN into it. To run the installer yourself, use the steps below.

Linux and macOSinstall.sh Windowsinstall.ps1 Robot detectorrobot.onnx (the installers fetch it for you) Source codecyberscout-src.tar.gz (this version)

Linux

  1. Install Docker with Compose. For GPU tracking, also the NVIDIA driver and the NVIDIA Container Toolkit.
  2. From the folder you saved install.sh to:
    bash install.sh --tarball …/downloads/cyberscout-src.tar.gz --model …/downloads/robot.onnx
    It asks before installing to /opt/cyber-scout; without the NVIDIA toolkit it warns and runs CPU-only.
  3. Open the address it prints and follow the setup wizard.

macOS

  1. Install Docker Desktop and start it.
  2. In Terminal, from the folder you saved install.sh to (usually cd ~/Downloads):
    bash install.sh --tarball …/downloads/cyberscout-src.tar.gz --model …/downloads/robot.onnx
  3. Open the address it prints and follow the setup wizard. Macs have no NVIDIA GPU, so tracking runs on the CPU: fine for following one event, about 4 times slower per match.

Windows

  1. Install Docker Desktop (WSL 2 backend) and start it. NVIDIA GPUs are used through WSL 2 with a current NVIDIA driver.
  2. In PowerShell, from the folder you saved install.ps1 to:
    powershell -ExecutionPolicy Bypass -File install.ps1 -Tarball …/downloads/cyberscout-src.tar.gz -Model …/downloads/robot.onnx
  3. Open the address it prints and follow the setup wizard.

The setup wizard

  1. The one-time setup code and your admin account.
  2. A Read API key from thebluealliance.com/account (stored only on your server).
  3. Your team number and season goal.
  4. The events to follow, then each event's video setup: which uploads or stream, layout boxes, a camera calibration (about 15 minutes, once per venue).

Then

  1. Admin, Teammates: a login and a role for each teammate (viewer, scout, strategist, admin).
  2. Optional: install the updater the script offers, for one-click updates with automatic rollback.
  3. Back up the install folder; data/app.db holds your TBA key and password hashes, so keep backups private.

More detail

Options, live streams, GPUs, backups and troubleshooting are in the deploy guide (deploy/README.md in the source) and in the docs overview.

Cyber-Scout Client for laptops

The same web app with a full local copy of your server's data. One file, nothing to install, no Python needed.

Windowscyberscout-client-windows-x64.exe macOS, Apple siliconcyberscout-client-macos-arm64 macOS, Intelcyberscout-client-macos-x64 Linuxcyberscout-client-linux-x64

Windows

  1. Your browser may warn first that the file isn't commonly downloaded: choose Keep (in Edge: the … menu, Keep, then Keep anyway).
  2. Double-click cyberscout-client-windows-x64.exe. If SmartScreen stops it: More info, then Run anyway.
  3. Your browser opens http://127.0.0.1:7600. Keep the console window open while you use it.

macOS

  1. In Terminal. Apple silicon (M1 and later):
    cd ~/Downloads
xattr -d com.apple.quarantine cyberscout-client-macos-arm64
chmod +x cyberscout-client-macos-arm64
./cyberscout-client-macos-arm64
    Intel:
    cd ~/Downloads
xattr -d com.apple.quarantine cyberscout-client-macos-x64
chmod +x cyberscout-client-macos-x64
./cyberscout-client-macos-x64
    Not sure which? Apple menu, About This Mac: a Chip named Apple M… is Apple silicon, a Processor named Intel is Intel.
  2. The builds aren't signed. If macOS still says it can't be opened: System Settings, Privacy & Security, Open Anyway, then run it again. (Right-click and Open no longer does this on macOS 15.)
  3. Your browser opens http://127.0.0.1:7600. Keep the Terminal window open while you use it.

Linux

  1. Make it executable and start it:
    chmod +x cyberscout-client-linux-x64
./cyberscout-client-linux-x64
  2. Your browser opens http://127.0.0.1:7600.

First run, every computer

  1. Settings, Connection: type your server's address, http://<your server's IP>:7560. The server installer prints it at the end.
  2. Test connection, then sign in with your Cyber-Scout account. Syncing starts at once.
  3. Choose media: none (data only, the default), small preview videos (about 15 to 20 MB per match), or every full video.

At the venue

Everything already synced keeps working offline. Notes, picklist edits and fixes wait in an outbox and are sent in order when the server is reachable again; a change is never applied twice.

Port in use?

Start it with --port 7601. Data lives in your user folder (Application Support on macOS, %APPDATA% on Windows, ~/.local/share on Linux).

Android

The app for phones and tablets in the stands and the queue line.

Android appcyberscout-android.apk

Install

  1. Download the APK on the phone and open it.
  2. When Android asks, allow installing apps from this source (your browser or Files app).
  3. If Google Play Protect warns about an unknown app: More details, then Install anyway. The app isn't on the Play Store yet.
  4. Open Cyber-Scout, enter your server's address and sign in.

Or just the browser

Any phone can open your server's address in the browser. Pages you've opened stay readable offline, and "Save this event for offline" in the connection menu copies the whole event.

System requirements

The server does all the work; clients only store data.

Server softwareDocker with Compose (Docker Desktop on macOS and Windows). Internet access to reach The Blue Alliance and YouTube.
Server GPUAn NVIDIA GPU is recommended: a match takes about 3 to 4 minutes. CPU-only works, about 4 times slower per match.
Before you startThe first install downloads and builds about 4 GB of Docker images (the worker image alone is about 3.5 GB), so run it on a fast, wired connection, not venue Wi-Fi. The installer warns when Docker has under 20 GB free or under 8 GB of memory.
Server memory8 GB for Docker. With Docker Desktop (macOS, Windows): Settings, Resources, at least 8 GB memory and 40 GB disk.
Server disk20 GB for the Docker images, plus room for videos. Livestream recording uses about 2 GB per hour (held under 60 GB per stream by default), preview copies about 2 GB per 75-match event, plus every full match video you keep. A NAS works for the media folder.
Blue Alliance keyA free Read API key from thebluealliance.com/account.
ClientsNothing to install besides the file itself. About 100 MB of data per event, more if you also keep videos.
